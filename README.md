# CODSOFT Personal Portfolio

Beginner-level CodSoft Web Development Internship project.

## Technologies
- HTML
- CSS

## How to run
1. Open this folder in VS Code.
2. Open `index.html`.
3. Right-click the file and choose "Open with Live Server" if you have the Live Server extension.
4. Or simply double-click `index.html` to open it in your browser.
